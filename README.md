# fortuna-visual-assets

Public static visual assets for **FORTUNA Notes** — market-observation illustrations only.

This repository hosts PNG previews used by the FORTUNA Blogger image embed workflow. It does **not** contain application code, private auth material, database files, or internal workflow artifacts.

## Contents

| Asset | Path |
|-------|------|
| FORTUNA brand card | `assets/fortuna/visuals/fortuna_brand_card_preview.png` |
| JANUS status card | `assets/fortuna/visuals/janus_status_card_preview.png` |
| SMCI observation card | `assets/fortuna/visuals/smci_observation_card_preview.png` |
| JANUS tracking timeline | `assets/fortuna/visuals/janus_tracking_timeline_preview.png` |

## Usage

After GitHub Pages is enabled on the `gh-pages` branch, image URLs follow:

```
https://{owner}.github.io/fortuna-visual-assets/assets/fortuna/visuals/{filename}.png
```

## Disclaimer

All visuals are for informational market-observation purposes only. Not investment advice. No guaranteed outcomes.

This repo is a **separate static-assets-only** package. The full FORTUNA project is not published here.
